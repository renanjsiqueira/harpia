# Vocabulário do flow no MVP do Harpia são 8 comandos de CRUD

O flow do MVP aceita exatamente: 'validate input', '<var> = create <Entity> from input', '<var> = load <Entity> by id', 'update <var> from input', '<var> = list <Entity>', 'save <var>', 'delete <var>', 'return <var>|nothing'. Os comandos find, require, emit, send e fail citados em prompt-initial.md §12 são M2 e devem disparar HRP1007 listando os 8 aceitos. Isso é limite declarado no README, não bug.
