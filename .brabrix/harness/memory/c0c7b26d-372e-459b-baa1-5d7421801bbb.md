# Prefixo de diagnóstico do Harpia é HRP, não HARP

O prompt inicial do projeto usa códigos HARP001/HARP100/HARP250, mas o design aprovado usa as famílias HRP1xxx (sintaxe), HRP2xxx (semântica), HRP3xxx (configuração), HRP4xxx (fora do MVP) e HRP5xxx (I/O). HRP supersede HARP em todo código-fonte, README e docs/errors.md. Ao ler o prompt-initial.md, traduzir mentalmente os códigos HARP para as famílias HRP.
